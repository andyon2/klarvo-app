## 2. What went well

1. **Consolidation instead of porting (7-3).** Deleting `HallucinationFilter.kt`, `SilencePreFilter.kt` and the Kotlin transcribe path removed drift by construction. The `0.02f`/`0.005f` self-desync "resolved by construction (no second source to desync against)".
2. **Relevance audit before resuming a parked epic** (`sprint-change-proposal-2026-09-10.md`). Four drift rows dropped as unreachable, ~40 % of 7.7 found already delivered, a phantom CI requirement removed. Conductor runs never targeted dead goals.
3. **Twin lock as fixtures, not prose (7-8).** `test-fixtures/twin-constants-vectors.json` is read by both harnesses; `Adr0017BoundaryGuardTest` fails the build if Kotlin re-grows STT/guard logic. The 7-3 AC9 promise ("7.7 later pins this") is finally enforced.
4. **Seam extraction as the standing remedy.** 7-1 (`shouldChunk` / `collectChunkResults` / `joinChunkResults`), 7-2 (`vadGateDecision`), 7-8 asserts through those seams so private constants stay private.
5. **Inversion tables as a format.** Every new assertion re-broken, measured, reverted; 7-8 even labels row E "NON-DISCRIMINATING" with a measurement instead of keeping a vacuous check.
6. **Explicit coverage statements** ("what the green numbers do and do NOT cover"), copied 7-2 → 7-8. This is what makes 662/0 and 168/0 honest.
7. **Emulator as the unattended structural oracle.** The laptop AVD carried all four 7-8 smokes and 7-2's stop-path proof; Andi's device time was reserved for perception (7-2) and the real network path (7-8).
8. **Headless conductor with seat costs.** 7-8 ran end-to-end as sibling `claude -p` workers under the `[workers]` grant, five human decisions, every seat logged in `seat-costs.jsonl`. R6 transcript grep found only benign hits.

## 3. Challenges and growth areas

1. **Record text drifts in the fixing commit.** 7-2 R2-P4 → R3-P5 (a fresh line anchor invalidated by the same commit); 7-8 R3 ("three round-2 resolution rows described code the same commit had deleted") and R4 (a miscount inside the sentence written to fix a miscount). Systemic cause: the fix worker edits the tree, then writes the record from memory, and line-number anchors age within the commit.
2. **The conductor treats record findings like code findings.** Each went through a full fix-plus-review round. Half of 7-8's budget went to text about the code. In round 4 the conductor applied the five record patches itself in the close-out commit — the right move, but ad hoc.
3. **Test-claim drift is the epic's recurring defect class.** 7-1: "6 of 8 stay green against the old code"; 7-2 round 1: all findings about test binding and comment accuracy; 7-8 exists to clean exactly this.
4. **A waived gate carried the only compiler (7-1).** Non-compiling Kotlin reached `review`. Replacement gate (device-free `kotlin-compiler-embeddable` verify) now standing — see `feedback_waived_gate_may_carry_the_only_compiler`.
5. **Gradle reports a false GREEN when only a fixture JSON changes.** The R3-P2 inversion in 7-8 went RED only under `--rerun-tasks`. Documented in `test-fixtures/README.md`, not fixed. Related: `android-smoke.sh` banner counts one result XML ("24 Tests" vs 168 real).
6. **`project-context.md` drifted one day after regeneration** (`3e181b6`, 2026-09-09): `test-fixtures/`, its README, the ADR-0017 boundary guard and the expanded role of `android-smoke.sh` are absent. ADRs, dependency pins and team rules are in sync.
7. **Long parking (2026-06-13 → 2026-07-19 / 2026-09-09).** Resuming needed the re-cut. The re-cut worked; the cost was that 7-3's fixture promise sat unenforced for three months.
8. **Device gates land on Andi** even for changes the machine proves almost fully (M9). Verification symmetry is met (he can produce the state with one dictation), but the epic's close waits on nobody — see decisions below.

## 4. Key insights

- **Drift is now a test failure, not a hunch.** Rust↔Kotlin twins are either gone (STT) or locked by shared fixtures (chunking, VAD gate, wav-rms, cleanup constants). Shared-core stays STT-only by design (`project_shared_core_is_stt_only`).
- **Record hygiene is a tooling problem, not a diligence problem.** Symbol anchors instead of line numbers; write resolution rows from `git diff`, not from memory; and an editorial pass instead of a review round when the findings are about the record.
- **Re-cut before resume** is cheaper than any conductor round on a stale target. It also caught that 7.7's "CI" never existed.
- **Human gates only where the human sees something the machine cannot**: perception, real network path. Everything structural belongs to the emulator.
