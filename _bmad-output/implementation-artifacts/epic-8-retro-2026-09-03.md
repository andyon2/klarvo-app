## What went well

- **The human gate found what three review layers and Chromium could not.** Copy and Delete were
  silent. Every review checked the re-skin against the canon, and the canon knew no click state.
  Andi saw the gap in minutes on the real screen. Correct-course turned it into 8-8 the same day.
- **Phase A did its job.** The canon was extended with the confirmed/undo states *before* the
  unattended run. Result recorded in `RUN-2026-08-21.md`: "No design question surfaced during Phase B".
- **Review round 2 earned its keep.** Fix round 1 in 8-8 latched a `StrictMode` ref and silently
  killed every Copy confirmation. Round 2 caught it. A green round-1 close-out would have shipped a
  dead feature.
- **The agent-triggerable Windows build** (`scripts/windows-build.sh`, `031a36a`) put 8-5 on Andi's
  screen the day it merged. Epic 11's AI-1 was not just met but exceeded.
- **Canon discipline held under pressure.** When code and canon disagreed (confirmation visible
  off-hover), the run left the canon untouched until Andi had seen the state, then wrote the
  exception (`.note .acts.responding`, fingerprint `028171af`). The canon records only what Andi saw.
- **Precedents that stuck:** Chromium preview gate (8-2) → standard; throwaway edits for unreachable
  states (8-5) → reused in 8-8; workers dispatched with an explicit `--allowedTools` grant instead of
  a blanket skip-permissions flag.

## What was hard (the lessons)

### 1. The retro ran late, and the witness had moved on
Andi, asked what convinced him: "kann ich nicht beurteilen … es ist eine Weile her, seit ich es
abgenommen hatte." The record carries the evidence (gate4 screenshots, MANIFEST rows), so nothing is
lost — but the retro's *human* input decays with every day the epic sits on `optional`. → AI-5.

### 2. Prose drifted from the tree in every story
8-2's reference counts were stale. The backlog said History lived in `VoiceNotesPanel.tsx`; it lives
in `App.tsx` (`285e523`). 8-5 wrote "≈24" alias sites; the tree had 46. 8-8 wrote "7 copy sites";
it was 5 + 1 + 1. Each story had to refute a written claim before it could build. 8-5 already wrote
the rule: "Re-verify counts against today's tree, not the reference branch. Grep before declaring done."

### 3. "Pure re-skin" grows logic, and better visuals expose old holes
8-5 ended with a load-state machine and a retry path. 8-8 needed an epic-scope amendment. The taller
empty state made a pre-existing load flash visible; the cleaner cards made the silent actions
visible. A re-skin story should ask in Phase A: *which response states does the canon not know?*

### 4. Fix rounds create their own regressions
8-5 round 2: a failed history load rendered nothing at all. 8-8 round 1: the `StrictMode` latch.
Both were caught only because a further round ran. A fix round without a re-review is a new
unreviewed change.

### 5. The story record is reviewed as hard as the code — and fails as often
Wrong counts, incomplete file lists, line anchors invalidated by the same commit, a "18/18" without
the qualifier that four of five Copy sites were never clicked. This is Epic 11's lesson 4 recurring.
The reviews caught it every time; the workers did not prevent it once.

### 6. A dead gate eats work
`cargo check --target x86_64-pc-windows-gnu` has died at the same `ort-sys` spot since 8-1. The 8-5
worker still installed mingw packages on the host twice to reach it. 8-8 concluded "do not run it at
all here". Unattended workers mutated the host for a gate that cannot go green. → AI-3.

## Significant discoveries

1. **Canon and ADR-0019 disagree on red.** Andi's 2026-08-21 acceptance made `Undo` red, and the
   canon recorded it. ADR-0019 §5 still says red is reserved for the destructive control. A later
   story reading the ADR would "repair" the colour. **Resolved at this retro by decision 1 below:
   Undo goes amber, which restores the ADR rule.** The ADR still needs an amendment recording the
   episode and the confirmed-state exception (`.acts.responding`).
2. **`project-context.md` (2026-08-17) has four load-bearing gaps.** It names `sync-and-build.ps1`
   as the canonical build, not `windows-build.sh` (with its absolute-path `powershell.exe` and
   run-in-background rules). It does not mention the puppeteer/Chromium harness that carries every
   desktop machine gate (`puppeteer ^24.38.0` is a runtime dependency). It claims "no separate
   `tests/` tree" — `src-tauri/tests/` has existed since March. It lists ADR-0020 as in force; the
   ADR index says superseded (the ADR header itself still says Accepted). Stack versions are clean.
3. **The sources are dirty, so a blind regeneration would only move the drift.** The team
   `CLAUDE.md` (`~/workspace/teams/klarvo/CLAUDE.md`, last changed 2026-06-30) says Settings live in
   SQLite (they live in `config.json`), says the repo is pushed only at releases (`windows-build.sh`
   pushes on every run), and names the licence PolyForm Noncommercial while `LICENSE` says Business
   Source License 1.1. Fix the sources first, then regenerate.

No epic re-plan is needed. No epic becomes invalid.

## Key takeaways

1. **The human gate is the only witness for interaction gaps a canon does not describe.** Three
   review layers and a Chromium harness passed silent Copy/Delete; Andi's eye did not. Budget the
   real-screen round for every surface epic, and ask the canon question in Phase A.
2. **A retro that is `optional` runs never — and its human input decays daily.** Run it in the same
   stroke as the close.
3. **Prose is not evidence.** Every Epic 8 story had to refute a written claim at the tree. Verify
   counts and locations before writing them down, and again before "done".
4. **Fix rounds are unreviewed changes until reviewed.** Round 2 in 8-8 stopped a dead feature; there
   is no cheaper insurance.
5. **Consolidated rules drift silently, and regenerating from dirty sources moves the drift instead of
   removing it.** Clean the sources, then regenerate.
