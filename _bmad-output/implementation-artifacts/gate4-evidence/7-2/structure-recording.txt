## Proxy trap hit on the way (tooling, not product) — see docs/backlog.md "Story 7-2 residuals"
  Attempt 1 of the stop-path case crashed: UnsatisfiedLinkError GroqSttBridge.nativeSilenceCheck
  (oracle-case3-attempt1-x86-split-crash.txt). Cause: android-smoke.sh installs with plain
  `adb install -r`; the x86_64 AVD then picks the x86_64 split, which carries no libklarvo_lib.so
  (Rust core is built for arm64 only). The two VAD-config cases above never reach JNI, so they were
  unaffected. Fix applied for the run: `adb install --abi arm64-v8a -r -g` (what
  android-emulator-smoke.sh already does) -> primaryCpuAbi=arm64-v8a, LicenseValidator logs
  "Native library libklarvo_lib loaded".
