## Decisions ledger (autonomous, technical-reversible — high-blast first)
1. **A failed backend delete still removes the row and swallows the rejection (blast: an
   unspecified error path on a rare failure; reversible).** Deferred rather than invented:
   both candidate shapes would have created user-visible error behaviour the story never
   specified, which is a design call reserved for Andi. Recorded in `docs/backlog.md`.
2. **Confirmation overrides the canon's hover-gated action row (blast: the acts row's
   visibility during the 1500 ms window; reversible).** The canon states
   `.note .acts { opacity: 0 }` with no exception for a confirmed state, but AC1 — Andi-approved —
   requires the confirmation to stay readable for its full 1500 ms. The code now carries the
   exception at three sites. The canon is deliberately NOT amended yet: it must record what Andi
   has actually seen. See the residuals.
3. **Search keystrokes commit pending deletes (blast: an undo window can end early on a
   keystroke; reversible).** AC7 explicitly permits it and Task 5.2 sanctioned it. Recorded, not
   re-engineered.
4. **AC1's no-layout-shift claim: measure, do not reserve width (blast: none; reversible).**
   Reserving width is a resize, which the Dev Notes forbid. The measurement came back clean under
   both labels, so nothing had to be built.
5. **Worker dispatch (blast: orchestration only, no product code; reversible).** The headless
   workers ran with an explicit `--allowedTools` grant plus `--permission-mode acceptEdits`
   instead of a blanket skip-permissions flag. Strictly more restrictive.
6. **GATE-4 observability (blast: test-only; reversible).** AC7 and AC8 are invisible in preview
   mode, because the `deleteHistoryEntry` mock re-serves all three rows on every refetch. The
   mock was instrumented throwaway-style and reverted afterwards — same precedent as 8-5.
   `src/tauri-commands.ts` is unmodified in the committed tree.

   accepts it, the canon gets one MANIFEST row recording the exception. If he does not, the code
   changes instead. Until then the canon and the code disagree, and `docs/backlog.md` says so.

   completed recording with raw text, which the preview mock cannot produce. Same hook, same call
   shape as the three history sites that were driven end-to-end; `tsc` covers the wiring.
