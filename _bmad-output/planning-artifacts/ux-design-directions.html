Notes & Open Items

v1 visual continuity adopted in this revision:
  • Waveform = 5 pill-shaped bars (border-radius 9999, fully-rounded ends) — verbatim from v1 FloatingBar.tsx::Waveform. Replaces the 64-vertical-line rendering.
  • Klarvo K-logo as brand-anchor inside the pill — verbatim from v1.
  • Abort button (red square, next to logo) — verbatim from v1 cancelRecording(). Visible during Recording / Live-Preview only. Discards audio, no paste. Cancellation in Cleanup-Done / Processing / Error states is not offered (matches v1).
  • Mode badge (Hold / AutoStop) at right edge — verbatim from v1.
Style assertions still open:
  • Pill Bar live-preview internal layout (text-above-strip vs side-by-side) — anchored to Step-7 §2.5.8 pattern, exact rendering TBD per implementation Story.
  • Live-Preview max-size 480×84 — placeholder per Step-7 anchor. Verify in implementation.
  • Settings sidebar 220px width — KaraFun-anchored, needs validation at 960×720.
  • Pill-Tag (provider badge) using `info`-tinted background — semantics-fit needs review.
  • Form-input `populated` state border is `success` — alternative is neutral border + ✓ icon. Step-12 (UX Patterns) decision.
  • Should abort be available during Processing state too (cancel API call)? v1 says no. MVP keeps v1 behavior; backlog item if user request emerges.

Android Bubble — not mocked here

Android Bubble shares the same state-machine (Step-7 §2.5.7) but renders via Compose Material3 with platform-native gestures and visibility rules. HTML mockups would misrepresent the actual surface. Concrete Bubble visuals deferred to the Android implementation Story.
