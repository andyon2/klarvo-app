# SmartScreen-Messaging: Textvorschlaege fuer Launch ohne Zertifikat

Erstellt: 2026-03-20 | Quelle: Product Strategist

## Strategie

Selbstbewusst kommunizieren, nicht entschuldigend. Source-available als Vertrauensbeweis nutzen.
Zertifikat erst bei Mainstream-Distribution-Push (~15 Verkaeufe / erster YouTube-Review).

## Vorschlag A — Kompakt (README / GitHub Releases)

**"Windows shows a SmartScreen warning on first launch. This is expected."**

> Dikta does not have a Windows code signing certificate yet — those cost $180-300/year. Since Dikta is source-available, you can review the code yourself before running it. Click "More info" → "Run anyway" to proceed. Once sales cover the cost, we will add a certificate.

## Vorschlag B — Selbstbewusst (Landingpage / Kaufseite)

**"Warum zeigt Windows eine Warnung?"**

> Windows kennt Dikta noch nicht. Code-Signierung kostet $300/Jahr — Geld das wir lieber in Entwicklung stecken als in einen Microsoft-Stempel. Dikta ist source-available: Jeder kann den Code auf GitHub pruefen. Wenn dir das nicht reicht, ist das legitim. Wenn doch: "Weitere Informationen" → "Trotzdem ausfuehren", und du kannst loslegen.

## Vorschlag C — Knapp (FAQ-Abschnitt)

**F: Windows sagt "Unbekannter Herausgeber" — ist das sicher?**

> Ja. Die Warnung bedeutet nur: kein bezahltes Signierzertifikat, kein Virusfund. Dikta ist source-available, der Quellcode liegt auf GitHub. Wer selbst nachschauen will: github.com/andyon2/dikta-public. Zertifikat kommt sobald die ersten Verkaeufe es finanzieren.

## Zertifikat-Trigger (wann investieren)

- Erster Mainstream-Kanal (YouTube-Review, ProductHunt)
- Conversion-Daten zeigen Drop bei "Download → Install"
- ~15 Verkaeufe (EUR 435) decken OV-Zertifikat fuer ein Jahr
- Vor erstem bezahlten Marketing-Kanal (sonst verschwendet Werbung Budget)
