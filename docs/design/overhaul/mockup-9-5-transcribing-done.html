Mockup 9-5 — die zwei offenen Stellen

Echte Canon-Tokens. Klick die Bubble „K" → ➤ Senden, dann siehst du transcribing → done. Wähle unten deine Varianten.

Modell-B steht für idle / recording / done schon. Hier geht es nur um zwei Lücken, die der erste Mockup nicht gezeigt hat: ① transcribing (was passiert, nachdem du ➤ gedrückt hast) und ② die done-Grün-Variante. Spiel den Ablauf durch, wähle je eine Variante, schreib unten kurz dazu.

⛓ Bindende Leitplanken (ADR-0019 §4′)
  • teal=bereit/Erfolg · amber=live/Aufnahme · rot=Abbrechen (nie Senden) · grün=done
  • recording = ein Cluster am Bubble-Platz: ➤ Senden (teal) · Waveform (amber, live) · ✗ Abbrechen (rot). Panel passiv.
  • amber erscheint nur während Aufnahme — in transcribing ist Amber verboten (nur teal).

Ablauf erleben

Tippe die Bubble „K" → recording. Dann ➤ = senden (→ transcribing → done → idle) oder ✗ = abbrechen (→ idle).
