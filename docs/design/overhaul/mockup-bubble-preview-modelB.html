⛓ Bindende Leitplanken (ADR-0019)
  • teal = Marke / bereit / Erfolg · amber = live/Aufnahme · rot = Abbrechen (nie Senden)
  • Abschließen/Senden = ➤ Senden-Icon (teal) · Abbrechen = ✗ (rot) · genau ein Interaktions-Ort (der Cluster) · Haken nur für done
  • Bubble-Form = Squircle, konstant · Android: Touch ≥48dp, kein WebView-Blur

Ablauf erleben

Tippe im Phone die Bubble „K" an → Aufnahme startet. Dann ➤ = abschließen/senden oder ✗ = abbrechen.

Modell B in Kürze:
• idle: Teal-„K", erscheint am fokussierten Feld.
• recording: „K" wird zum Senden/Abbrechen-Cluster mit mitlaufender Waveform als Live-Cue; das Panel zeigt nur Text + Zeit (keine Waveform, kein roter Knopf — nur der Cluster bewegt sich).
• done: Grün + Haken, dann zurück zu idle.
